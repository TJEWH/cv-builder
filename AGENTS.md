# Textarea autosave

Every textarea must follow [the shared textarea behavior](docs/textarea-behavior.md). Use `AutosaveTextarea` (or `MarkdownTextarea` for CV content), keep typing in a local draft, and save on blur/Enter. Use `v-model.lazy` when model changes trigger persistence. Publish pending drafts with `commitPendingTextareas()` before snapshotting or replacing an editor, then await its persistence layer's flush before navigating away. Do not save on each input event or after a typing debounce. Shift+Enter inserts a newline; IME confirmation must not trigger a save. Preserve native double-click word selection and press-and-drag text selection; triple-click selects the whole textarea. Textarea commits must not implicitly approve disclosure, upload files, or submit workflows.
